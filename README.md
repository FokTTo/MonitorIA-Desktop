# Monitor IA — Desktop (downloads)

## Instalar (3 cliques)

1. Abra a [última release](https://github.com/FokTTo/MonitorIA-Desktop/releases/latest)
2. Descarregue **`MonitorIA_Para_Instalar_2026.09.21.41.zip`** e **extraia**
3. Duplo clique em **`INSTALAR.cmd`** -> prima tecla / **Continuar**
4. O app abre sozinho — crie conta com email

Actualizações seguintes: automáticas ao abrir o atalho «Monitor IA».

## Se o Windows bloquear (Smart App Control / «vírus»)

1. Clique direito no **ZIP** -> Propriedades -> marque **Desbloquear** -> OK  
2. Apague a pasta extraída, extraia de novo, e volte a correr `INSTALAR.cmd`
