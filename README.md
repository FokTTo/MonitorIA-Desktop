# Monitor IA — Desktop (downloads)

Instalação **automática** para Windows (sem `MonitorIA.exe` — evita bloqueio do
*Controle inteligente de aplicativos* / Smart App Control).

## Instalar (1 minuto)

1. Abra a [última release](https://github.com/FokTTo/MonitorIA-Desktop/releases/latest)
2. Descarregue **`MonitorIA_Para_Instalar_2026.09.20.14.zip`** (único pacote recomendado)
3. Extraia para uma pasta permanente (ex.: `Documentos\MonitorIA`)
4. Duplo clique em **`1_INSTALAR_AQUI.vbs`**
5. O app abre sozinho — crie conta com email

Pronto. Actualizações futuras: ao abrir o atalho, o app actualiza sozinho.

## O que acontece no instalador

- Desbloqueia ficheiros descarregados (Mark of the Web)
- Instala Python se faltar
- Instala bibliotecas + atalho «Monitor IA»
- Abre o app automaticamente
- Ao criar conta / entrar, o perfil sincroniza com o administrador

## Não use

O pacote `MonitorIA_Cliente_Portavel_*.zip` (EXE) — o Windows pode bloquear.
Só existe em releases antigas / modo avançado.

Versão actual: **2026.09.20.14**
